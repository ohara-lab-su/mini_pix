# D08-W0313 個体校正

<a href="https://ohara-lab-su.github.io/mini_pix/en/manual/calibration.html">English</a>

このページは **D08-W0313固有**の校正プロトコル（2025-02-11）を記録する。工場校正値を他のMiniPIX個体へ転用してはならない。記載のPIXetバージョンは校正時の **1.7.8.936** であり、実行コードのSDKバージョンと同一とは限らない。

|---|---:|
| Timepix Clock | 10.0 MHz |
| Ikrum | 1 |
| FBK | 156 |

| Preamp | 225 |
| THL均一化：平均 | 751.666 |

| 10分安定性試験 | 99.469 % |
| 60 keV付近のToT分解能 σ | 2.728 keV |

デジタル・バイアステストの不良画素は0であるが、X線試験では83である。**検査方法の異なる数字を同一視しないこと。** バイアスリーク試験は15–150 Vの範囲で実施され、表中のリーク電流は各点0.0000 µAと記載されている。これは全条件でリークがゼロであるという一般保証ではない。

ToTエネルギー校正の平均係数は A=1.642、B=22.945、C=19.630、T=4.368。これは証明書に記載された校正パラメータであり、`set_threshold()` に直接渡す値ではない。APIの `set_threshold(threshold_kev)` は **keV単位**でPIXetへ設定を要求する。

判定はイメージング（Counting）・トラッキング（Energy）ともに **B / Usable**。メーカーが本個体について使用可能と判定したものであり、すべての測定条件での性能保証を意味しない。

出典：D08-W0313 Calibration Protocol pp.1–4。
