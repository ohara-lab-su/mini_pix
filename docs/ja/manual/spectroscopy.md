# エネルギー測定とスペクトル

<a href="https://ohara-lab-su.github.io/mini_pix/en/manual/spectroscopy.html">English</a>

D08-W0313はTimepixと500 µm Siセンサーを使用する。ToTモードはエネルギー付与に対応した信号の時間幅を画素単位で測定するが、**ToT値からエネルギーへの換算には校正が必要**である。PIXet ProのマニュアルにはDACスキャン、しきい値均一化、クラスタリングの機能が説明されている。ただし、これらはGUI/PIXet側の機能であり、添付の `MiniPixCtrl` が自動で実行するものではない。

D08-W0313の校正証明書にはFe、In、Amを用いたToT校正結果が記録され、平均係数 A=1.642、B=22.945、C=19.630、T=4.368、Amでの校正確認（エネルギー 59.518 keV、σ=2.728 keV）が記載されている。**係数の適用式や画素別係数の保存場所は、添付された制御コードだけからは確定できない。** 係数を独自の式へ代入して再校正したと説明してはならない。

製品データシートに示されるSiセンサーの典型的なX線検出エネルギー範囲は5–60 keVであり、これは個体校正の最低しきい値3.697 keVと同じ意味ではない。測定結果をスペクトルとして扱う際は、動作モード、しきい値、バイアス、クロック、測定時間、校正状態を記録する。

出典：Calibration Protocol pp.2–4、MiniPIX Datasheet p.4、PIXet Pro User's Manual pp.22–33。
