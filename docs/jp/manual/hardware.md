# 実機の仕様と安全

<a href="https://ohara-lab-su.github.io/mini_pix/en/manual/hardware.html">English</a>

本プロジェクトが対象とする実機は **MiniPIX-D08-W0313** である。個体の校正証明書に記載された読み出し部は MiniPIX（シリアル番号 2746）、チップは **Timepix**、センサーは **Si 500 µm**、モデルは **MNXTXS-XP5210520** である。一般的な MiniPIX 製品の標準構成（Si 300 µm）と混同しないこと。

| 項目 | D08-W0313 の仕様 |
|---|---|
| 画素数 | 256 × 256 |
| 画素ピッチ | 55 µm（端部・隅の画素は例外） |
| 有効面積（公称ピッチ換算） | 約 14.08 × 14.08 mm² |
| 読み出し | USB 2.0 High-Speed |
| チップ | Timepix（Timepix3 ではない） |
| センサー | シリコン 500 µm |
| 計数・エネルギー・時間モード | Event / ToT / ToA |
| 最大フレームレート（製品仕様） | 55 fps（読み出し時間は代表値 19 ms） |

製品仕様書の 55 fps は上限であり、Python制御・保存・通信を含めた実効レートを保証しない。読み出し中はセンサーからの信号を取得できない。MiniPIXは**認証済みの線量計ではない**。放射線防護の判断を本装置の値だけに依存させない。

使用条件は周囲温度 0–50 °C、非結露で湿度 85 % 未満。製品資料では背面の冷却板またはペルチェ素子による **22 °C** への温度安定化を要求している。チップまたはCPU温度が55 °Cを超えると自動停止する。USBハブは性能や安定性を損なう場合がある。

**センサー表面とワイヤーボンドには触れないこと。清掃も行わないこと。** カバーを外す際やカバーなしで扱う場合は特に注意する。ワイヤーボンドの機械的損傷は保証対象外である。真空での使用は一般製品の標準保証条件ではなく、メーカーとの適合確認が必要である。

出典：MiniPIX Standard Datasheet pp.2–8、Quick Start Guide p.2、D08-W0313 Chip Detail p.1、Calibration Protocol p.1。
